# droboquis-capxur
Screen recording tool built with the Screen Capture API. This project was developed as part of a selection process for a Software Engineering Internship position, which helped me secure my first job in the technology field.

## Languages and Frameworks
- **Frontend**: TypeScript, NextJS, and ReactJS
- **Backend**: Appwrite
- **Testing**: Playwright

## How to Use
1) Clone the Droboquis Capxur repository
   ```bash
   git clone https://github.com/cyrqrz/droboquis-capxur.git
   ```
2) Navigate to the repository directory
   ```bash
   cd droboquis-capxur
   ```
3) Install dependencies
   ```bash
   npm install
   ```
4) Run the development server
   ```bash
   npm run dev
   ```
5) Access the application at `localhost:3000`
6) Use the "Start Recording" button to begin

## Features
- Webcam integration with screen capture
- Webcam preview
- Replay of the last recording
- Integration between audio, video, and webcam
